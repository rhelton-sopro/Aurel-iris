O que é: o artefato de lastro definitivo do motor. Para CADA campo do Stage 1, reúne o(s) elemento(s) Bardon em % (derivados das emoções-núcleo pelo mapa emoção→elemento, tabela-emocao-elemento-PROPOSTA.md, com a conta curta) e, para cada elemento que o órgão carrega, os DOIS POLOS: o 🟢 polo equilibrado (o recurso/face harmônica desse elemento — MTC + assinatura+) e o 🔴 polo desequilibrado (a carga/ferida — emoções verbatim da tabela-achado-emocao-COMPLETA.md, com tags de fonte). As crenças são a forma COGNITIVA das emoções listadas no próprio polo + os temas de Hay/Dias do órgão.

A correção estrutural (o que mudou nesta versão): a versão anterior colava o elemento no eixo equilíbrio/desequilíbrio (tratava "Fogo = a carga" e usava o truque ⚡Ar pro lado recurso). ERRADO. Cada elemento tem dois polos. O fígado é Fogo → existe um Fogo equilibrado (assertividade/coragem/decidir), não só a raiva. O mesmo órgão que carrega Água tem Água equilibrada (sentir fundo e soltar) E Água desequilibrada (ressentimento). O lado equilíbrio de um campo é o polo + dos MESMOS elementos que ele carrega — não a troca por outro elemento. O ⚡Ar foi eliminado.

Como o Stage 2 usa: consulta esta tabela como piso determinístico — ela dá o leque legítimo (elemento, polo, emoção, crença) ancorado no achado; o Stage 2 intui por cima (escolhe, dentro deste leque, o que o exame + a história do cliente sustentam, e escreve na voz do produto). Nada aqui é sentença: é hipótese a explorar. Este lastro é INTERNO — as tags de fonte (N/Br/MTC/Hay/Dias) existem para rastreio e NUNCA vão ao doc do cliente.

Guardrails (não-negociáveis)

  • Emoção/crença = HIPÓTESE ancorada no achado, a explorar na devolutiva — nunca causa fixa, sentença ou culpa. Enfoque emocional/comportamental, não-médico.
  • ZERO invenção. Cada emoção/crença/elemento ancora no lastro. Crença = forma cognitiva de uma emoção listada NO MESMO POLO (a emoção-mãe tem que aparecer).
  • Crenças NUNCA genéricas (anti-Forer). "Eu mereço ser feliz" serve pra qualquer um → proibido. Têm que ser específicas do tema do órgão.
  • Hay entra só como TEMA de crença, nunca o framing "você criou / é culpa / precisa perdoar".
  • LOCKS de elemento (Bardon): MEDO/insegurança = 💧Água · raiva/impulso/controle = 🔥Fogo · tristeza/mágoa/ressentimento = 💧Água · alegria/vínculo expansivo/sociabilidade = 💨Ar · apego/retenção/preocupação/ruminação/teimosia = 🌍Terra · mente/pensamento/raciocínio/comunicação = 💨Ar. Insegurança = medo-Água sobre falta de chão-Terra (não é emoção-Terra). Segurança/base/firmeza = 🌍Terra no polo 🟢.
  • Dois polos por elemento (a regra desta versão): todo elemento que o órgão carrega tem um 🔴 (a carga/ferida) E um 🟢 (o recurso, o mesmo elemento em equilíbrio). O 🟢 vem da face harmônica (MTC/Dias) + o polo + da assinatura. Nunca trocar de elemento pra achar o recurso — o recurso é o polo + do PRÓPRIO elemento.
  • Ar honesto (não forçar, mas não sumir): o 💨Ar aparece (a) PRIMÁRIO nos campos MENTAIS — a faculdade do pensamento é Ar (cerebrum_motor, cerebellum_sensory, pineal_hipotalamica, sistema_nervoso_autonomico); (b) no polo 🟢 saudável de comunicação/voz (boca/tireoide), respiração (pulmões) e vínculo/sociabilidade (coração/linfa). NÃO forçar Ar como carga onde o conteúdo é medo/controle/apego.
  • "Análise/ruminação/controle/julgamento" são *modos do centro MENTE* — mas em Bardon a faculdade mental é 💨Ar; a ruminação é o polo 🔴 do Ar, o raciocínio claro é o polo 🟢. As emoções LIGADAS (autoexigência, ansiedade de performance, medo de errar, culpa) entram no elemento que o lock manda.
