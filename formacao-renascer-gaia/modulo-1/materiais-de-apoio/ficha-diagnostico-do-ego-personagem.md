# Material de apoio — Ficha: Diagnóstico do Ego-Personagem
### Exercício de autoinvestigação (Aula 5) · ~40 min

> ⚠️ **Postura:** isto é um **mapa para tomar consciência**, não um rótulo para se encaixar. Você é uma mistura de máscaras, em camadas, conforme o contexto. Responda com curiosidade e **sem se julgar** — cada máscara foi, um dia, a sua inteligência tentando te proteger.

---

## Parte 1 — As 4 perguntas-chave
Responda devagar, deixando o corpo responder junto.

1. **Quem eu preciso ser para ser amada/aceita?**
   (Ex.: forte, útil, perfeita, invisível, divertida, durona…) ____

2. **O que eu NÃO posso, de jeito nenhum, mostrar aos outros?**
   (Ex.: fraqueza, raiva, necessidade, tristeza, desejo, "burrice"…) ____

3. **O que acontece no meu corpo quando essa máscara está no comando?**
   (Onde tensiono? Mandíbula, ombros, peito, barriga, garganta? Como fica meu fôlego?) ____

4. **Do que essa máscara um dia me protegeu?**
   (Que situação da minha história ela ajudou a sobreviver?) ____

## Parte 2 — Mapa das máscaras (marque o quanto cada uma ressoa: 0 a 3)

| Máscara | Lema oculto | Ressoa (0–3) | Em que situações aparece? |
|---|---|---|---|
| O Forte / Controlador | "Não posso fraquejar" | | |
| O Agradador | "Se eu te agrado, você fica" | | |
| O Invisível | "Se eu não apareço, não me machucam" | | |
| O Perfeito | "Se eu não erro, sou amado" | | |
| O Rebelde | "Rejeito antes de ser rejeitado" | | |
| O Cuidador | "Valho pelo que faço pelos outros" | | |
| O Normótico | "Está tudo bem, nada a ver aqui" | | |

> Some onde marcou 2 ou 3. As máscaras de pontuação mais alta são as suas **couraças principais** — não defeitos, mas os pontos por onde o Fogo vai trabalhar.

---

## Parte 3 — A máscara principal

- Minha máscara **principal** hoje é: ____
- Ela nasceu provavelmente quando/porque: ____
- O que ela me **deu** (o ganho real): ____
- O que ela me **custa** hoje (o que me impede de respirar/viver): ____

---

## Parte 4 — O ser por trás

- Quando eu **largo** essa máscara, mesmo que por instantes, eu sou/sinto: ____
- A última vez que me senti **real e espontânea** (sem máscara) foi: ____
- O que o meu ser essencial gostaria de fazer, se não tivesse medo: ____

---

## Parte 5 — A gratidão que liberta
Escreva uma carta curta à sua máscara principal:

> *"Querida [nome da máscara], obrigada por ter me protegido quando ______. Você foi importante e eu te honro. Hoje eu estou aprendendo a respirar mesmo sem você no comando o tempo todo. Você pode descansar um pouco. Eu cuido daqui."*
