# Phase 7 — UI Design Contract

> Visual and interaction contract for Fase 7 (Análise LLM). Generated by gsd-ui-researcher,
> verified by gsd-ui-checker. Phase 7 introduces three new user-facing surfaces in the
> existing Aurel Iris Next.js dashboard: trigger CTA on `/leituras/[id]`, streaming
> reception of the LLM analysis, and a 13-section editor at `/leituras/[id]/editar`.

## Spacing Scale

Inherits Tailwind v4 default scale (multiples of 4px via `--spacing` token). Declared usage for Phase 7 surfaces:

| Token | Value | Usage in Phase 7 |
|-------|-------|------------------|
| xs | 4px (`gap-1`, `p-1`) | Icon-to-text inline gaps inside Buttons and Badges |
| sm | 8px (`gap-2`, `p-2`) | Tight clusters: Badge + status text, Accordion trigger inner padding |
| md | 16px (`gap-4`, `p-4`) | Default Card padding, between Accordion items, label↔input gap |
| lg | 24px (`gap-6`, `p-6`) | Section padding inside Cards; vertical rhythm between editor sections; banner top spacing |
| xl | 32px (`gap-8`, `p-8`) | Page hero spacing (CTA card on `/leituras/[id]`), top of editor page |
| 2xl | 48px (`gap-12`, `py-12`) | Empty state vertical padding (matches existing `/leituras/page.tsx` `py-16` family) |
| 3xl | 64px | Reserved — not used in Phase 7 |

**Exceptions:** none. Streaming progress bar (Skeleton) uses `h-4` (16px) × natural width; section accordion trigger uses `h-12` (48px touch target on mobile editor view).

## Typography

3 sizes + 1 reserved for the report markdown body. 2 weights total.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.5 (`leading-normal`) | Form labels, helper copy, badge text, banner body, audit metadata details |
| Report body | 16px (`text-base`) | 400 (regular) | 1.6 (`leading-relaxed`) | Markdown-rendered report sections inside preview pane (longer-form reading) |
| Heading | 20px (`text-xl`) | 600 (semibold) | 1.3 (`leading-snug`) | Accordion section triggers ("1. Constituição", "2. Estrutural Física", …); Card titles |
| Page title | 24px (`text-2xl`) | 600 (semibold) | 1.2 (`leading-tight`) | "Análise da leitura" page title on `/leituras/[id]` and `/leituras/[id]/editar` (matches existing `/leituras` h1) |

**Markdown rendering inside report preview:** `react-markdown` + `remark-gfm` with Tailwind Typography prose plugin (`prose prose-sm prose-neutral max-w-none`) so `##` and `###` inside the section content stay visually subordinate to the Accordion trigger. **DO NOT** introduce a third weight (700/bold) — `prose` defaults to 600 for `<strong>` which matches our semibold token.

**Citation tokens** (`[ancorado em: features.X]`) render as `<code>` from remark-gfm: `text-[13px]` (`text-xs` family), monospace `var(--font-mono)`, `bg-muted` background, `px-1 rounded` — visually distinct from prose body but not loud.

## Color

Achromatic neutral palette inherited from existing `globals.css`. NO new color tokens this phase.

| Role | Token | Usage in Phase 7 |
|------|-------|------------------|
| Dominant (60%) | `--background` (oklch 1 0 0 light / 0.145 0 0 dark) | Page background of `/leituras/[id]` and `/leituras/[id]/editar`, editor surface |
| Secondary (30%) | `--card` + `--secondary` + `--muted` (oklch 0.97 / 0.205 dark) | Cards wrapping each phase surface (CTA card, audit banner card, accordion items, preview pane background) |
| Accent (10%) | `--primary` (oklch 0.205 light / 0.922 dark) | **Reserved for:** "Gerar análise" primary CTA, "Salvar edição" primary button, "Entregar ao cliente" primary button. NOTHING ELSE. |
| Destructive | `--destructive` (oklch 0.577 0.245 27.325) | **Reserved for:** Alert (destructive variant) for audit banners D-A1/D-A2; "Entregar ao cliente" confirmation dialog destructive cue (final irreversible state); blocked-save error toast |

**Accent reserved-for list (explicit, exhaustive for this phase):**
1. **"Gerar análise"** primary CTA on `/leituras/[id]` hero card (single instance per page).
2. **"Regenerar análise"** primary CTA on `/leituras/[id]` (visible after first generation; disabled state when `regeneration_count >= 3` OR `report_delivered IS NOT NULL`).
3. **"Salvar edição"** primary button at the bottom of `/leituras/[id]/editar` (sticky on scroll).
4. **"Entregar ao cliente"** primary button at the bottom of `/leituras/[id]/editar` (separate button, separate row from "Salvar edição" per D-U3).

All other interactive elements (Accordion triggers, "Voltar", links to client/reading lists, `<details>` toggles for the read-only disclaimer) use `variant="outline"`, `variant="ghost"`, or default text/Link styling. **No accent on Accordion chevrons** — they use `text-muted-foreground`.

**Banner colors (D-A1 + D-A2):** Both audit banners use the shadcn `Alert` `variant="destructive"`. They appear as the FIRST element inside the editor's main column (above the first Accordion), pinned visible until the underlying condition resolves (anchor rate recomputes ≥95% on next save, or forbidden vocab array becomes empty after edit). They are NOT dismissible by user click — they are state-driven only, so the terapeuta cannot accidentally hide a real LGPD-06 violation.

**Layout decisions (Claude's Discretion resolved):**
- **Accordion vs `<details>`:** shadcn Accordion (Radix-based, accessible by default, matches the project's installed primitive style). `<details>` does not compose with Tailwind theme tokens cleanly.
- **Edit/preview arrangement:** Vertical stack (Textarea above, preview below) inside each Accordion item. Horizontal split would feel cramped at the natural reading width and force horizontal scroll on mobile editor view.
- **Open-by-default:** First 3 sections (Constituição, Estrutural Física, Indicações Sistêmicas) auto-open so the terapeuta lands on actionable content without an extra click. Remaining 10 collapsed.
- **Sticky footer:** Always visible during scroll so save/deliver are one click away regardless of which section the terapeuta is reviewing.
- **Edited indicator:** Per-section subtle `· editado` text token whenever `report_delivered[key] !== report_generated[key]`. Lets the terapeuta scan which sections diverge from the original at a glance. Calculation runs client-side from the loaded jsonb props — no extra DB call.

## Streaming Visual Cue (D-S2 surface)

The streaming UX is the most novel interaction in Phase 7. Contract:

- **During stream:**
  - Hero card replaces "Gerar análise" empty state with "Streaming" state
  - `Progress` bar fills proportionally as each `### N. Título` boundary is detected and persisted
  - A 13-row checklist below the progress bar shows received sections (✓ + Lucide `Check` icon, 14px, `text-muted-foreground` until matched then `text-foreground`) and pending sections (Skeleton row of `h-6 w-full bg-muted rounded`)
  - Hint text reassures the terapeuta refresh is safe (D-S2 contract)
  - StatusBadge in header shows ephemeral client-side variant `Gerando…` (label only — no enum change). Variant: `secondary` with a Lucide `Loader2 animate-spin` icon prefix, 14px
- **On stream complete:**
  - Sonner toast: `Análise gerada. Revise as 13 seções antes de entregar.`
  - Hero card transitions to State C (post-generation card) with primary `Editar análise` CTA
- **On stream error / disconnect:**
  - Hero card shows error state copy + `Tentar novamente` button
  - Already-received sections remain in `report_generated` jsonb (D-S2 partial save) — re-entering the page renders State C if at least 1 section is present, with a subtle warning chip `Geração incompleta — 7/13 seções` and a `Continuar geração` outline CTA
- **On page refresh mid-stream:**
  - RSC reads current `report_generated` jsonb (could be partial)
  - If partial AND there is no in-flight stream owned by this browser tab, show State C with the partial warning + `Continuar geração`
  - If complete, show State C normal

## Accessibility Floor

These are the contract minimums for Phase 7 surfaces. Checker validates.

| Concern | Contract |
|---------|----------|
| Touch targets | All Buttons and Accordion triggers ≥ 44×44px on mobile (`h-11` for primary, `h-12` for accordion) |
| Focus visibility | Inherited from shadcn `focus-visible:ring-ring/50` on all interactive elements — DO NOT override |
| Form labels | All Textareas have an associated `<Label>` referencing `htmlFor` (use existing `Form` primitives if going via react-hook-form; otherwise plain `Label` + `id`) |
| Streaming announcements | Add `aria-live="polite"` on the streaming progress region so screen readers announce "7/13 seções recebidas" updates without interrupting reading |
| Error alerts | shadcn `Alert` already has `role="alert"` |
| Dialog | Reuses Radix Dialog focus trap; default-focus the Cancel button on destructive confirmations |
| Color contrast | Achromatic palette already passes WCAG AA on `--foreground` over `--background` (oklch 0.145 vs 1.0 = 14.4:1) |

## State Persistence Contract (UI-visible)

| State source | UI consumer | Refresh behavior |
|--------------|-------------|------------------|
| `readings.report_generated` (jsonb) | `/leituras/[id]` State machine + `/leituras/[id]/editar` initial values | RSC reads on every navigation; D-S2 incremental writes mean refresh during stream shows progress |
| `readings.report_delivered` (jsonb) | `/leituras/[id]/editar` Textarea initial values (falls back to `report_generated` if NULL) | RSC; preserves all edits across navigation |
| `readings.audit_metadata` (jsonb) | Audit banners on `/leituras/[id]/editar`; audit chip on `/leituras/[id]` | RSC; recomputed server-side on each save |
| `readings.regeneration_count` | Regenerate button counter + disabled state | RSC; hard-guarded server-side too (D-S4) |
| `readings.is_delivered` + `delivered_at` | Locks editor to read-only after delivery | RSC; UI conditionally renders read-only mode (no Textareas, just preview panes; no Save/Deliver buttons; banner: `Análise entregue em {delivered_at} — somente leitura.`) |
