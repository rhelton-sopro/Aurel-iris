## Decisions Made

- **AnalysisHero is shared between V2 and legacy paths.** The hero handles empty/streaming/State-C UI; V2's adaptive report body renders below it only when the report exists. Did NOT swap the hero out for V2 — keeps streaming UX consistent across versions and avoids duplicating the empty-state copy.
- **Optional `reportVersion` prop added to `AnaliseClientProps` in Task 1.** Allows Task 1 to compile cleanly (the page already passes the prop) while Task 3 wires the actual switch. Default `'1.0'` preserves legacy behavior if any caller forgets the prop.
- **`V2_KEYS_ORDERED` inlined in the client.** Cannot import `REPORT_V2_TOP_LEVEL_KEYS` from `lib/anthropic/report-schema.ts` because that module declares `import 'server-only'`. Sync-marker comment in the client points to the canonical source.
- **Final-block detection via `,"advanced_analysis":` sentinel.** Counts 0..7 from key transitions, then bumps to 8 on the sentinel. Documented cosmetic limitation: a truncated stream that ends inside `clinical_note` content (before the `,"advanced_analysis":` separator hits) keeps the final Skeleton until `router.refresh()` retrieves the persisted `report_v2`.
- **Early-return for V2 in editar/page.tsx.** Cleaner than wrapping the entire return in a ternary — keeps the legacy block as a contiguous chunk so future readers can verify zero regression at a glance.
