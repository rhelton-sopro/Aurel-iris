**2. [Rule 1 - Bug] Test drain pattern triggered ESLint no-unused-vars**
- **Found during:** Task 2 (analyze-v2.test.ts initial draft)
- **Issue:** Used `for await (const _ of result.stream) { /* drain */ }` 6× to consume the async iterable before awaiting finalize(). The `_` identifier is the conventional ignore name in JS, but the project's ESLint config (`@typescript-eslint/no-unused-vars`) flags it without the leading-underscore-pattern exception. `pnpm lint` reported 7 new warnings (1 from a `(_params: unknown)` mock arg + 6 from the drain loops).
- **Fix:** Refactored mock to `vi.fn(() => ...)` (removed the unused `_params` arg entirely). Added `drainStream(stream): Promise<string>` helper near the top of the test file that consumes the iterable into a string, replaced all 6 drain loops with `await drainStream(...)`.
- **Files modified:** apps/web/lib/anthropic/__tests__/analyze-v2.test.ts
- **Verification:** `pnpm lint` returns to baseline 9 warnings (was 16 mid-task); all 8 analyze-v2 tests still GREEN.
