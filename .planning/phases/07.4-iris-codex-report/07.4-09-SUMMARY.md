# Plan 07.4-09 — Rebrand + Env + Manifest + Server-Only Schema Split

## Summary

Final plan in Phase 7.4. Rebrands the product from "Aurel" / "Aurel Iris" to **Iris Codex** across every user-visible surface, applies the founder-approved tagline **"A íris como mapa do ser."**, and unblocks `pnpm build` by splitting `lib/anthropic/report-schema.ts` into a server-only zod schema module + a client-safe shared module.

## What Shipped

1. **User-visible rebrand sweep** (commit `9a78917`): manifest, root layout metadata, landing page, login/signup, capture flow header, admin header, dashboard sidebar, Anthropic SDK User-Agent header, env example files. PROJECT.md and README.md rewritten with new positioning (Iris Codex ↔ Sopro da Origem brand separation per D-BR1).
2. **Audit-vocabulary brand protection** (commit `72350f2`): 4th `aurel_brand` pattern set in `forbidden-terms.json` + `audit-vocabulary.mjs`. `manifest.test.ts` flipped from Wave 0 RED stub to GREEN with 5 assertions (name/short_name/description tagline/description no 'Aurel'/icons).
3. **Regression sweep documentation** (commit `2121ee8`): `deferred-items.md` recording 4 pre-existing issues out of Plan 09 scope.
4. **Tagline replacement** (commit `452fe99`): founder rejected initial draft "Plataforma clínica de relatórios iridológicos funcionais adaptativos" (front-loaded iridology framing). Replaced everywhere with "A íris como mapa do ser." — cleaner, drops iridology language, leans into mapping/meaning angle.
5. **Server-only schema split** (commit `536d0c4`): created `lib/anthropic/report-schema-shared.ts` (no `server-only`) housing const arrays + plain TS interfaces; `report-schema.ts` keeps the zod runtime + re-exports for backwards compat. 12 client surfaces re-pointed to the shared module. Compile-time contract assertions guard against drift. `pnpm build` now passes.

## Why the Schema Split Mattered

Plan 07.4-07 introduced client editor components (`SystemTendencyCardEditor`, `IntegrativeAxesEditor`, `BilateralFindingsEditor`) that import `TENDENCY_LABELS` etc. from `report-schema.ts`. That file had `import 'server-only'` from Plan 00. Next.js webpack refused to bundle a server-only module into a client chunk, breaking production builds. The fix preserves type-safety end-to-end while letting client editors reach runtime constants without crossing the server-only barrier.
