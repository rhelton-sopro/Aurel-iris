## Sampling Rate

- **After every task commit:** `pnpm test:run --changed` (vitest only-changed flag — fast feedback)
- **After every plan wave:** `pnpm test:run && pnpm audit:vocabulary && pnpm lint` (full suite + vocab + lint)
- **Before `/gsd-verify-work`:** Full suite + lint + build green; manual UAT (SC-10) gate
- **Max feedback latency:** ~60s (full suite); ~15s (--changed)
