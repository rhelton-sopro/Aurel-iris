# Phase 07.4 Plan 14: UAT-2 Fixes (UI + Prompt + RAG) Summary

## One-liner

UAT-2 fixes — UI title-strip + all-collapsed default + system.md §3 Cronorichio + §4/§6/§10/§13 visual-anchoring + GLOBAL CALIBRATION RULE + biografia_temporal RAG concern.

## Context

Founder UAT-2 verdict 2026-05-14 surfaced 3 issues on the Plan 13 regenerated Nailli reading:

1. **UI bug**: section titles rendered the `##` markdown markers literally in the editor preview (heading line duplicated — once in accordion trigger, once at top of body).
2. **UX bug**: first 3 sections opened by default; founder wants ALL collapsed to force progressive disclosure.
3. **Prompt bug**: §3/§4/§6/§10/§13 produced Forer/Barnum-style generic narratives ("a 37-year-old woman who...") that fit any client — not iris-anchored claims that require THIS iris to be true.

Plan 14 addresses all 3 in 3 atomic source commits + 1 docs commit.

## Implementation

### Task 1 — UI fixes (commit 4357380)

**EditorAccordion.tsx:**
- `defaultValue={['1_constituicao_temperamento', '2_mapa_organico', '3_linha_tempo_emocional']}` → `defaultValue={[]}`. All 14 sections collapsed on initial render; the founder expands what they want to review.
- AccordionTrigger inner span: `{s.number}. {s.title}` → `§{s.number} — {s.title}`. Em-dash (U+2014) + § glyph mirror the markdown heading format `## §N — Title`.

**EditorSectionItem.tsx:**
- New module-level constant `STRIP_LEADING_HEADING_RE = /^[ \t]*#{2,3}[ \t]+§?[ \t]*\d{1,2}[ \t]*[\p{Pd}.][^\n]*\n+/u`. The `u` flag is mandatory for `\p{Pd}` (Unicode Dash Punctuation category — covers em-dash, en-dash, hyphen-minus, all dashes used historically by both 14-section `## §N — Title` and legacy 13-section `### N. Title` shapes).
- Applied to `deliveredValue` ONLY before passing to ReactMarkdown in the preview pane. Textarea source view stays raw — the editor is supposed to show the raw markdown including the heading so a power user can re-render after edits.

**Tests:**
- `EditorAccordion.test.tsx`: title assertions migrated from `/1\. Constituição/` to `/§1 — Constituição/`. New test asserts all 14 sections collapsed by default (querySelectorAll('textarea').length === 0).
- `EditorSectionItem.test.tsx`: two new tests cover the strip behavior — one for the 14-section heading shape, one for the legacy 13-section shape. Both also assert the textarea retains the raw markdown.

**Result:** 13/13 tests GREEN (was 11/11; +2 strip tests). `grep -c` acceptance criteria all met.

### Task 2 — system.md prompt iteration (commit 8cb3fac)

**GLOBAL CALIBRATION RULE** (founder verbatim): inserted between "Identidade de marca" and "Regras de linguagem" sections (after line 58). Text:

> Se uma afirmação caberia em qualquer mulher de 35-40 anos, está errada.
> Se ela exige que ESTA íris seja como é, está certa. Em dúvida, diga menos
> e ancore mais.

This rule prevails over all subsequent instructions. Cada parágrafo must pass the filter: does it cite a specific iris finding (sector + hour + sign type), a named structure (fiber, lacuna, pigment, ring, mark) with identifiable position, OR is it a psychosomatic/temporal axis explicitly anchored in a prior finding from the SAME report? If NO — rewrite or omit.

**§3 Linha do Tempo Emocional**: full rewrite. Each marker MUST contain 6 mandatory fields in order:
1. Specific iris sign (sector hour + eye + sign type)
2. Cronorichio mapping (Lo Rito Italian / Jensen / Brazilian — SKIP marker if not anchorable)
3. Topography (organic zone of the sector)
4. Suggested quality (emotional reading — hypothesis, not diagnosis)
5. **Resolution status — 3-category enum, founder verbatim**:
   - "Marca aparenta estar em processo de resolução"
   - "Marca ativa, com expressão atual no organismo"
   - "Marca encapsulada — registro presente mas não-ativo no momento"
6. Hedge as hypothesis

Includes verbatim BEM-ancorado worked example (hour 4 LE + Cronorichio 11-14 years + thyroid topography + expression-contention quality + active-mark status + ressonância invitation) and a MAL-ancorado forbidden example ("Por volta dos 12-16 anos, uma adolescente que engoliu mais do que expressou"). Quantity: min 3, max 7. No artificial floor — emit what the iris anchors.

**§4 Padrões Emocionais Ativos**: added "Ancoragem visual (mandatória)" clause. Every emotional pattern cited MUST reference a specific finding from §2/§3 in the SAME report. Without anchoring, omit the pattern.

**§6 Heranças Transgeracionais**: full rewrite with BILATERAL GROUND OBRIGATÓRIO. A transgenerational hypothesis is valid only when the sign is bilateral (both eyes, same/mirrored sector, similar grade). Unilateral signs are biographic-personal, not lineage. Lists 5 categories of bilateral signs accepted as ground (primary pigmentations, bilateral nervous rings, bilateral lymphatics, mirrored toxic marks, bilateral stromal structures). Quantity: 0-3 hypotheses with explicit graceful-empty handling ("A íris desta cliente não apresenta sinais bilaterais marcantes...").

**§10 Dimensão Arquetípica**: added "Ancoragem ANTES de interpretação" clause. Name 3-5 specific findings BEFORE any symbolic reading. Theme emerges FROM findings, doesn't float above them. Limit: 1-2 paragraphs.

**§13 Síntese Integrativa**: full rewrite. 3-5 concrete fios; each fio must cite at least one specific iris sign from §2/§3 AND connect 2-3 systems/sections (psychosomatic axis, temporal mark + current system, bilateral inheritance + current manifestation, archetypal theme + finding).

## Deviations from Plan

**One judgment call recorded** — Rule 3 style (blocking issue auto-fix):

**Updated `score-weights.ts` SECTION_THEMES Record** — the plan listed only types.ts + section-queries.ts + analyze.ts as RAG files to touch. But `score-weights.ts` declares `Record<ReportSection, string[]>` with compile-time exhaustiveness; adding `biografia_temporal` to the union without an entry would have broken tsc. The plan critical_constraints explicitly anticipated this case ("If you find that the existing REPORT_SECTIONS array in analyze.ts is referenced by audit.ts or diff.ts in a way that adding biografia_temporal would break things..."). Resolved by adding `biografia_temporal: ['psicossomatica', 'comportamental']` with a comment explaining the dimension choices.

**Test-fixture detail discovered during Task 1** — initial strip-test attempt used quoted-attribute JSX syntax `deliveredValue="## §1 — ...\n\n..."` which JSX treats as literal backslash-n (not newlines). Tests failed with `<h2>...</h2>` rendering the entire string. Fixed by extracting the fixture into a `const deliveredValue = '...'` template literal and passing via `{deliveredValue}` expression syntax — JS string literals interpret `\n` as newline. Documented inline as the pattern.

**No other deviations.** Plan executed exactly as written; no Rule 4 architectural checkpoints needed; no auth gates; no scope expansion beyond what the plan critical_constraints anticipated.
