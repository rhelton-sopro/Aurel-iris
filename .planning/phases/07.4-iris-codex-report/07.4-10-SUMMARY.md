## What was done

Surgical edits to 6 consumer files + 2 retained-surface files. No file deletions in this commit — the goal was to break all references to about-to-be-deleted v2 modules first so Task 2 could remove them cleanly.

- **`apps/web/app/api/readings/[id]/analyze/route.ts`** — Dropped the entire `if (reading.report_version === '2.0') { ... }` branch (lines 118-292 in the pre-edit file). Removed `report_v2`, `report_v2_delivered`, `report_version` columns from the SELECT. Simplified gate (d) from `reading.report_version === '2.0' ? reading.report_v2_delivered != null : reading.report_delivered != null` to a plain `reading.report_delivered != null` check.
- **`apps/web/app/(dashboard)/leituras/[id]/page.tsx`** — Dropped `ReportAdaptiveView` + `AdvancedAnalysisCTA-as-footerSlot` mount, `isV2` + `hasReportV2` + `reportVersion` computed vars, `ReportV2` type import, and `report_v2*`/`report_version` from the SELECT. - **`apps/web/app/(dashboard)/leituras/[id]/editar/page.tsx`** — Dropped the entire `if (isV2 && reportV2) return <ReportAdaptiveEditor .../>` early-return block, `isV2` + `reportV2` computed vars, `ReportAdaptiveEditor` import, `ReportV2` + `AuditV2Result` type imports, and `report_v2*`/`report_version` from the SELECT. - **`apps/web/app/(dashboard)/leituras/[id]/analise-client.tsx`** — Dropped `AdaptiveAnalysisStream` import, `V2_KEYS_ORDERED` constant, `detectBlocksReceived` function, `reportVersion` prop, `isV2`-aware stream-parse branch, and version-aware toast copy. Now always streams via the legacy `AnalysisStream` with `^### N. ` boundary regex.
- **`apps/web/app/actions/analise.ts`** — Dropped the `saveReportV2Delivered` and `deliverReportV2` server actions in their entirety, the module-private `safeArray<T>()` helper (used only by `deliverReportV2`), and all v2-only imports (`runAuditV2`, `classifyAllSystemsV2`, `reportV2Schema`, `ReportV2`, `AuditV2Result`, `ReportV2EditDiff`). ## Deviations from Plan

Two minor inline deviations during execution, both pre-flagged in the `<critical_constraints>` section of the executor brief:

### 1. [Rule 3 - Cross-module type ownership transfer] VocabularyAuditBanner now owns AuditV2Hit + AuditV2Result types

- **Found during:** Pre-Task-1 dependency analysis
- **Issue:** `VocabularyAuditBanner.tsx` (retained per DC-10) imports `AuditV2Hit` + `AuditV2Result` from `@/lib/anthropic/types-v2`, which is in the deletion list. After Task 2 the banner would fail to compile.
- **Fix:** Inlined both interfaces into `VocabularyAuditBanner.tsx` as exported `interface` declarations. Updated the banner test to import `AuditV2Result` from the banner module itself instead of `types-v2`. The shapes are trivial (3 string arrays + a JSON-validation flag + a timestamp; hit = field+term+count) so inlining is cheaper than introducing a new sibling types file. Plan 11/12 may re-centralize these types when revisiting the audit pipeline.
- **Files modified:** `apps/web/components/readings/VocabularyAuditBanner.tsx`, `apps/web/components/readings/__tests__/VocabularyAuditBanner.test.tsx`
- **Commit:** `6343607`

### 2. [Rule 3 - Dead helper sweep] safeArray module-private helper dropped from analise.ts

- **Found during:** Task 1 (analise.ts edit)
- **Issue:** `analise.ts` declared a module-private `function safeArray<T>(v: unknown): T[]` used only by `deliverReportV2`. With `deliverReportV2` deleted, `safeArray` becomes dead code.
- **Fix:** Dropped the `safeArray` declaration alongside the v2 actions. Pre-flagged in the executor's `<critical_constraints>` ("ensure no non-async exports remain"). Project-wide `safeArray` continues to live in `@/lib/utils` and is consumed by `VocabularyAuditBanner` and others.
- **Files modified:** `apps/web/app/actions/analise.ts`
- **Commit:** `6343607`
