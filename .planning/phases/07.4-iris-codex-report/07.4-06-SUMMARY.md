## Decisions Made

- **Reused `safeArray<T>()` from `@/lib/utils`** instead of inlining per-component. The helper was already exported (and is the source of the MEMORY rule on jsonb iteration safety).
- **Type-only imports from `@/lib/anthropic/report-schema`** — that file has `import 'server-only'` at the top. `import type { ReportV2, SystemTendency, TendencyLabel, AxisStatus }` is erased at compile time by TypeScript, so the server-only barrier is preserved even though these components are eligible for client rendering.
- **BilateralFindingsCard returns null internally** on `!asymmetry_present` instead of being conditionally rendered by the parent. Co-locates the omission rule with the component; the parent always renders the component but the DOM is identical.
- **ClinicalNote has no Card wrapper** by deliberate UI-SPEC choice (lines 408-410) — at the bottom of the report stack, the clinical disclaimer is meant to feel like footer prose, not another headline card.
- **Defensive client-side sort** on `systems_with_tendency` by `tendency_grade` desc — the prompt instructs Sonnet to emit sorted, but UI cannot regress visual order if the LLM drifts.
- **GradeBar uses literal Tailwind class strings** (not dynamic `bg-${color}-${shade}` interpolation) — Tailwind v4 static analysis requires literal tokens or the styles get tree-shaken. The 5-element palette is fixed by D-UI4 anyway.
