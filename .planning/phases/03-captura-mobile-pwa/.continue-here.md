## Infrastructure Notes (para não repetir erros)

- `.vercelignore` usa gitignore syntax: `supabase/` sem `/` inicial bate qualquer subdir chamado `supabase/`; use `/supabase/` para ancorar à raiz
- `NEXT_PUBLIC_*` vars são baked no build — adicionar no Vercel não basta; precisa de **Redeploy**
- Supabase Auth exige Redirect URLs configuradas em Authentication > URL Configuration
- Magic link exige `NEXT_PUBLIC_SITE_URL` = URL de produção (sem trailing slash)
