## Discussion turns

### Turn 1 — Approach choice

**Presented:** Deep-dive comparison of 6 hypotheses from DISCUSSION-NOTES (A. Hough tuning / B. Color pre-seg / C. U-Net CASIA / D. Haar cascade / E. UX zoom-out REJECTED / F. SAM/U²-Net/SegFormer/Custom CNN). Each with mechanism, files affected, cost (deps, model size, cold-start, inference), likelihood, effort, risks. Comparison table summarizing all 6.

**Claude's recommendation:** B → C cascade. B is zero-deps, high-likelihood, fast-iteration (3-4d). C is the hammer if B fails (5-7d, ~50-200MB model, ~100ms GPU inference). A/D are tuning that may not fix root cause; F is heavier than C.

**Question asked:** "Qual abordagem para 07.1.5 detect/segment robustness?"
**Options presented:**
1. B primeiro → C como fallback (recommended)
2. C direto (U-Net CASIA pre-trained)
3. B + D em paralelo, ensemble vote
4. Research-phase primeiro (deixa pesquisador decidir)

**User answer:** B primeiro → C como fallback (recommended).

**Decision captured in CONTEXT.md:** D-01, D-02, D-03.
