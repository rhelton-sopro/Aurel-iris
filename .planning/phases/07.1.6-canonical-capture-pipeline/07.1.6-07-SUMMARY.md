## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking issue] .gitignore negation pattern needed `/*` wildcard + parent re-include**
- **Found during:** Task 1 verification
- **Issue:** Plan's literal action was to add only `!apps/web/scripts/output/landmarks-probe-sonnet-4-6.json` after the existing `apps/web/scripts/output/` directory ignore. Tested with `git add -n apps/web/scripts/output/landmarks-probe-sonnet-4-6.json` → exit 1 ("paths are ignored"). Git's documented semantics: "It is not possible to re-include a file if a parent directory of that file is excluded." The simple negation could not work as a literal patch.
- **Fix:** Added the negation block as `!apps/web/scripts/output/` (re-include parent) + `apps/web/scripts/output/*` (ignore contents via wildcard) + `!apps/web/scripts/output/landmarks-probe-sonnet-4-6.json` (specific re-include). This three-line pattern makes the negation functional while preserving the wholesale ignore for every other file/dir inside `scripts/output/`.
- **Files modified:** `.gitignore` (+8 lines including comment)
- **Verification:** `git add -n` dry-run on all 4 patterns confirmed correctness:
  - `apps/web/scripts/output/landmarks-probe-sonnet-4-6.json` → exit 0 (addable)
  - `apps/web/scripts/output/landmarks-probe-sonnet-4-6-pre-protocol.json` → exit 1 (ignored)
  - `apps/web/scripts/output/haiku-landmarks-probe.json` → exit 1 (ignored)
  - `apps/web/scripts/output/crops-sonnet-4-6/` → exit 1 (ignored)
- **Committed in:** `629bda4` (Task 1)
- **Plan verify line impact:** Plan's `<verify><automated>` for Task 1 also expected `grep -q "^apps/web/scripts/output/$"`. That literal line is gone (replaced with `apps/web/scripts/output/*`). The functional outcome (everything except the golden remains ignored) is preserved; the literal regex is not.
