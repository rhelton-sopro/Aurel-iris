## Auditor Notes (informational, non-blocking)

- **Stronger-than-claimed mitigation on T-08:** the threat plan said "JSON parse + type checks + comparisons return false on NaN → fallback". The code also has defaults that drive `radius_pct=0` → automatic geometric-sanity fail. Belt-and-braces — stronger than declared.
- **D-04 kill-switch double-checked:** `process.env.CANONICAL_CAPTURE_ENABLED !== 'false'` at `index.ts:109` means ANY value other than the literal string `'false'` (including unset, empty, `'true'`, `'no'`) keeps canonical ON. This is the documented default-ON semantics. Endpoint at `route.ts:27-30` does NOT re-check the flag, delegating to the orchestrator — consistent with the threat model.
- **T-29 founder gate verified twice:** `isFounderEmail` is correctly checked in `apps/web/app/api/admin/calibration/photos/[reading_id]/route.ts:50-52`. Confirmed that `RecanonicalizeButton.tsx` is rendered only from `app/admin/calibration/[id]/page.tsx` (which is under `/admin/*` middleware gate) — and the canonicalize endpoint itself is per-tenant-ownership-gated, not founder-gated, which is correctly what T-16 (not T-29) claims.
- **Probe golden fixture inspected:** `landmarks-probe-sonnet-4-6.json` was sample-read (L1-50) and contains UUID reading_id, model name, token counters, image dimensions, and raw Sonnet JSON text with iris bbox + canthus landmark coordinates and confidence numbers. No patient name, email, birth_date, image bytes, or therapist identifier. Mitigation claim holds.
