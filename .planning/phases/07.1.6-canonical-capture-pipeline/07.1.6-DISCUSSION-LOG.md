## Trust gate — fallback comportamento

| Option | Description | Selected |
|--------|-------------|----------|
| Fallback to original | Passa imagem original ao Modal pra essa foto; `canonical_status='fallback'` em metadata; Modal lida; outras 5 fotos seguem canonical. | ✓ |
| Block + ask for retake | Mostra erro pro terapeuta; refaz foto; re-canonicaliza; segue. | |
| Hard fail reading | Marca reading inteira como failed; terapeuta refaz tudo. | |
| Founder pick per-photo via admin | `canonical_status='quarantined'`; founder aprova/re-canonicaliza via `/admin/calibration` depois. | |

**User's choice:** Fallback to original (Recommended)
**Notes:** Preserva liveness e UX; metadata torna o caso 1/6 audit-able sem fricção pro terapeuta. Aceita degradação no canonical_status='fallback' como hit aceitável dado que Modal still produz output (mal mas produz).

## Trust gate — mecanismo de detecção

| Option | Description | Selected |
|--------|-------------|----------|
| Cross-angle + geometric | (A) bbox center nos centrais 60% + radius_pct in [0.05, 0.30] + (B) por olho, center spread entre 3 ângulos > 0.08 do mediano → outlier. Pre-Modal. | ✓ |
| Geometric only | Só (A). Mais simples mas NÃO pega right_frontal failure mode. | |
| Cross-angle + Modal post-check | (B) + retroactive flag via Modal Hough off-center. Mais robusto mas exige mudança Modal-side. | |
| Cross-angle + confidence threshold | (B) + conf < 0.5. Belt-and-suspenders mas conf não ajuda muito (right_frontal era 0.78). | |

**User's choice:** Cross-angle + geometric (Recommended)
**Notes:** Pre-Modal apenas, mantém Modal contract inalterado. Cross-angle catches o right_frontal failure mode mais provavelmente; geometric pega edge cases distintos. Threshold value 0.08 from empirical right_frontal delta = 0.10.

## Trust gate — retry policy

| Option | Description | Selected |
|--------|-------------|----------|
| No retry, fallback direto | Gate falhou → fallback. Simples, latência ótima. | ✓ |
| 1 retry com prompt diferente | Re-call Sonnet com rephrasing. +$0.008 + 3s. Ganho real só se Sonnet for prompt-sensitive. | |
| 1 retry com Opus | Cascade pra Opus on fail. +$0.025 + latência. Não testado empiricamente. | |
| Cascade Sonnet → rephrasing → Opus → fallback | Máximo esforço. +$0.033 + 6-9s. Overkill pro 1/6 que cai em fallback. | |

**User's choice:** No retry, fallback direto (Recommended)
**Notes:** Mantém pipeline simples; retry pode ser adicionado em follow-up se 1/6 piora pós-rollout. Wave C corpus tuning continua com inputs canonical na maior parte dos casos.

## Claude's Discretion (planner decide)

- **Onde vive o canonicalize:** server-side em apps/web (novo `POST /api/capture/canonicalize` endpoint vs inline em `finalizeReadingAction` server action) — planner escolhe com base em testability + idempotência.
- **Storage path convention:** `{therapistId}/{readingId}/canonical/{eye}_{angle}.jpg` paralelo a `originais/`. Mirror de `lib/capture/storage-path.ts`.
- **Schema additivo:** `reading_images.canonical_storage_path text NULL` + `processing_metadata.canonical_status: {ok, fallback, disabled}` + `processing_metadata.canonical_sonnet_usage` (tokens + cost).
- **Parallel Sonnet calls:** 6 em paralelo via `Promise.all`. Cuidar Tier 1 rate limits.
- **Sharp resize quality:** `lanczos3` + JPEG quality default (92) ou 95 pra preserve fiber detail.
- **Sonnet prompt:** reusa SYSTEM_PROMPT do probe script; planner refina se necessário.
- **Anthropic SDK reuse:** decide se canonical compartilha `apps/web/lib/anthropic/client.ts` (Phase 7 client) ou usa instance separada (modelo diferente — Sonnet pra bbox vs report).
- **`/admin/calibration` UI surface:** adicionar `canonical_status` badge + "Re-canonicalizar" botão. Pequena extensão.
- **Probe script commitable:** add header com runbook + remove Nailli hardcoded (positional arg required).
- **Test surface:** Wave 0 RED scaffolding (pure functions sanity check) → Wave 1 endpoint → Wave 2 wiring.
