// Current (audit.ts:31)
const ANCHOR_RE = /\[ancorado em: features\.[\w.\[\]]+\]/g

// Proposed (relaxed): anything inside `[ancorado em: ... ]` with optional
// surrounding backticks and optional `features.` prefix.
// - `i` flag: case-insensitive ("Ancorado", "ANCORADO", etc)
// - `u` flag: Unicode-correct (already in SENTENCE_SPLIT_RE; consistency)
// - `g` flag: global (multi-occurrence in a sentence)
// Inside the brackets we accept ANY non-`]` content, so:
//   [ancorado em: features.constitution]                ✓
//   [Ancorado em: `feature.path`]                       ✓
//   [Ancorado em: `features.sectors[3].findings`]       ✓
//   [ancorado em: constitution]                         ✓ (sem prefixo)
//   [ancorado em:   `features.foo`  ]                   ✓ (whitespace tolerant)
//   [Markdown link](url)                                ✗ (não casa "ancorado em")
//   [outro conteúdo]                                    ✗
const ANCHOR_RE = /\[\s*ancorado em\s*:[^\]]+\]/giu

<!--
extractForbiddenHits — skip LGPD-aware
-->

// New constant — negative-construction patterns that, when preceding a
// forbidden term in the same phrase, indicate LGPD-correct usage and must
// NOT be counted as a hit.
//
// Whitelist (founder-validated 2026-05-09):
//   - "não um <termo>"      (e.g., "não um diagnóstico médico")
//   - "não uma <termo>"     (e.g., "não uma cura definitiva")
//   - "não constitui <termo>"
//   - "não é <termo>"
//   - "não substitui <termo>"
//   - "não representa <termo>"
//   - "não significa <termo>"
//
// Implementation strategy: variable-width lookbehind via regex flag is
// supported in Node 20+, but to keep FORBIDDEN_VOCAB_RE source simple and
// preserve the meta-invariant test, we apply the skip in
// `extractForbiddenHits` via a per-match preceding-text check.
//
// For each match, slice `text[Math.max(0, match.index - 30) ... match.index]`
// (30 char lookback window — covers "não substitui " = 14 chars + buffer)
// and test against NEG_CONTEXT_RE. If matched, skip the hit.

const NEG_CONTEXT_RE = /n[ãa]o\s+(um|uma|constitui|é|e|substitui|representa|significa)\s*$/iu
// Note: includes both 'é' and 'e' to handle accent-stripped variants Sonnet
// occasionally emits (e.g., "não e um diagnóstico").

// extractForbiddenHits — modified loop body:
while ((m = regex.exec(text)) !== null) {
  const matchStart = m.index
  const lookbackStart = Math.max(0, matchStart - 30)
  const preceding = text.slice(lookbackStart, matchStart)
  if (NEG_CONTEXT_RE.test(preceding)) continue  // LGPD-correct usage
  const term = m[0]!.toLowerCase()
  counts.set(term, (counts.get(term) ?? 0) + 1)
}

<failure_modes>
- Lookback de 30 chars não cobre construção super-prolixa ("…não substitui de forma nenhuma um diagnóstico…"). Acceptance: NEG_CONTEXT_RE casa o pattern direto; usos elaborados raros caem para o gate humano via banner. Não é regressão (o banner ainda dispara em hits genuínos).
- Variable-width lookbehind funciona em Node 20+ mas não em Node 18. Mitigação: adotamos a estratégia de slice + match em vez de lookbehind no regex source (preserva FORBIDDEN_VOCAB_RE simples e portátil).
- Regex `[^\]]+` em ANCHOR_RE pode casar greedy em colchetes aninhados ("[ancorado em: features.[idx][0]]"). Acceptance: o pattern atual já tinha `[\w.\[\]]+` aceitando colchetes literais; a versão relaxada preserva esse comportamento via `[^\]]+`. Edge case: "[ancorado em: x] outro [bla]" — o regex casa só "[ancorado em: x]" (porque `[^\]]+` para no primeiro `]`). ✓
- Skip LGPD-aware pode mascarar construção positiva onde "não" se refere a outra cláusula ("Esta análise não é completa. Sugere diagnóstico…" — sentence-split deveria separar mas aqui o lookback de 30 chars vai para a frase anterior). Acceptance: edge case raro; sentence-split já é feito no anchor count, não no forbidden scan. Hit positivo em frase separada continua disparando (o lookback não casa NEG_CONTEXT_RE porque "completa. Sugere " não tem o pattern).
- Caso `é` vs `e` em "não é diagnóstico": Sonnet pode escrever sem acento. NEG_CONTEXT_RE inclui ambos via `(é|e)`. Trade-off: "não e diagnóstico" (sem acento, gramaticalmente errado) também é skipped — aceitável dado que o cenário é hit-evitando, não permissivo demais.
</failure_modes>
