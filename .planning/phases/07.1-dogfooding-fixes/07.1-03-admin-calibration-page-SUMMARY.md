  deve re-marcar como revisada após editar. Evita "anotação editada mas ainda
  marcada revisada" como estado silencioso.

## Deviations

### Rule 1 — `/404` rewrite → status 404 response (T2)

**PLAN's interface code:**
```ts
return NextResponse.rewrite(new URL('/404', request.url))
```

**Problema:** `/404` route não existe no App Router (verificado via
`find apps/web/app -name "not-found*" -o -name "404*"` → empty). O rewrite
falharia silenciosamente com Next.js renderizando uma página vazia ou erro.

**Fix:** `return new NextResponse(null, { status: 404 })`. Defense-in-depth
preservado via `app/admin/layout.tsx` que chama `notFound()` (renderiza Next's
built-in not-found page com styling apropriado). Resultado UX: middleware
bloqueia raw request → status 404; layout chamado se middleware furar →
not-found page properly styled.

## Bugs descobertos em produção (3)

### Bug 1: FeaturesDisplay crash em data drift (commit `9c59d6b`)
**Symptom:** "TypeError: g.map is not a function" em /admin/calibration/[id].
**Root cause:** vision_features é jsonb; legacy/partial rows poderiam ter
strings/objects onde TS types declaram arrays. `??` e `&& length > 0` não
catch wrong-type.
**Fix:** safeArray<T>() helper em lib/utils.ts. Aplicado em 5+5 call sites
em FeaturesDisplay + TechnicalReportCopyButton (sectors, findings, indicators,
warnings, asymmetry_notes).
**Lesson registrada:** sempre operar em arrays garantidos quando consumindo
jsonb fields, mesmo com type declarations otimistas.

### Bug 2: 'use server' export hygiene (commit `c9c7152`)
**Symptom:** Mesmo "g.map is not a function" continuou em produção depois do
Bug 1 fix. Stack trace apontava page bundle (client). dev funcionava.
**Root cause:** `app/actions/calibration.ts` tem `'use server'` no topo +
exportava IRIS_COLOR_OPTIONS / CONSTITUTION_OPTIONS como const arrays. Per
Next.js docs, todo export de 'use server' file vira Server Action (RPC stub).
Em produção, AnnotationForm importava esses consts mas no client bundle
chegavam como references opacas, NÃO arrays. dev compila tolerante; prod
aplica full transform.
**Fix:** Novo arquivo `apps/web/lib/calibration/constants.ts` com os consts
+ types. 'use server' file só exporta async functions.
**Lesson registrada (anti-pattern crítico):** files com 'use server' SÓ podem
exportar async functions. Constants/types em arquivo sibling.

### Bug 3: RLS broken auth.users subquery (commit `bfbadf9`)
**Symptom:** Founder clicou "Salvar diagnóstico" → toast vermelho
"permission denied for table users". Latente desde 0009 (nunca disparou
porque AnnotationForm também não tinha sido testado).
**Root cause:** Policies em 0009/0010 usavam
`(select email from auth.users where id = auth.uid()) = 'rhelton@gmail.com'`.
Role `authenticated` NÃO tem SELECT em auth schema (privado do Supabase).
Subquery throws permission denied durante avaliação de RLS.
**Fix:** Migration 0011 substitui por `(auth.jwt() ->> 'email') = ...`. Lê
email direto do JWT em memória, sem tocar auth.users. Aplica nas duas tabelas.
**Lesson registrada:** NUNCA query auth.users de RLS. Use auth.jwt() ->>
'email' (ou auth.uid() se UUID basta).
