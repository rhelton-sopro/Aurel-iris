    Replace `vision-service/pipeline/compose.py` content with an implementation that:

    1. Header: `from __future__ import annotations` + `import numpy as np`.
    2. Module docstring referencing RESEARCH.md "Code Examples — Photometric Composition" and the calibration note (weights are starting defaults).
    3. Module constant `ANGLE_WEIGHTS = {"frontal": 0.4, "lateral": 0.4, "backlight": 0.2}` — exact values from RESEARCH.
    4. Module constant `_DEFAULT_WEIGHT = 0.33` for unrecognised angles.
    5. Function `photometric_combine(segmented_images: list[dict]) -> dict`:
       - Validate input non-empty: `if not segmented_images: raise ValueError("compose_empty_input")`.
       - Take H, W from `segmented_images[0]["segmented_image"].shape[:2]` and assert all subsequent images share that shape (raise `ValueError("compose_shape_mismatch")` if not).
       - Initialize `composite = np.zeros((H, W, 3), dtype=np.float32)` and `total_weight = 0.0`.
       - For each `seg` in input: read `angle = seg.get("angle", "frontal")`; weight = `ANGLE_WEIGHTS.get(angle, _DEFAULT_WEIGHT)`; `img = seg["segmented_image"].astype(np.float32)`; `composite += img * weight`; `total_weight += weight`.
       - After loop: if `total_weight == 0`: raise `ValueError("compose_zero_weight")` (defensive — unreachable in practice).
       - Final composite: `out = np.clip(composite / total_weight, 0, 255).astype(np.uint8)`.
       - Return dict: `{"segmented_image": out, "iris_circle": segmented_images[0]["iris_circle"], "pupil_circle": segmented_images[0].get("pupil_circle")}`.
    6. Remove the existing `raise NotImplementedError(...)` line.

    NOTE: Do NOT mutate input dicts. Do NOT use `cv2.add` (overflow concerns). Do NOT skip the `total_weight` denominator.
  </action>
