    4. Function `daugman_polar(composite_image: dict) -> np.ndarray`:
       - Validate input is dict-like with keys `segmented_image` and `iris_circle`. Raise `ValueError("normalize_invalid_input")` if either is missing.
       - Extract `image = composite_image["segmented_image"]`, `(cx, cy, r_iris) = composite_image["iris_circle"]`.
       - Extract pupil: `pupil = composite_image.get("pupil_circle")`. If `pupil is None`: `r_pupil = r_iris * 0.35` (RESEARCH Pattern 6 line 723 fallback). Else: `_, _, r_pupil = pupil`.
       - Build coordinate grids:
         ```python
         theta = np.linspace(0.0, 2 * np.pi, POLAR_ANGULAR, endpoint=False, dtype=np.float32)
         r_ratio = np.linspace(0.0, 1.0, POLAR_RADIAL, endpoint=False, dtype=np.float32)
         radii = r_pupil + (r_iris - r_pupil) * r_ratio  # shape (POLAR_RADIAL,)
         cos_t = np.cos(theta)  # shape (POLAR_ANGULAR,)
         sin_t = np.sin(theta)
         # Outer product: map_x[r, theta] = cx + radii[r] * cos_t[theta]
         map_x = (cx + np.outer(radii, cos_t)).astype(np.float32)
         map_y = (cy + np.outer(radii, sin_t)).astype(np.float32)
         ```
       - Call `polar = cv2.remap(image, map_x, map_y, cv2.INTER_LINEAR, borderMode=cv2.BORDER_CONSTANT, borderValue=0)`.
       - Return polar (already shape `(POLAR_RADIAL, POLAR_ANGULAR, 3)` because remap output shape matches map1.shape).
    5. Remove the existing `raise NotImplementedError(...)` line.

    Performance note: `np.outer` is the SIMD-friendly equivalent of a double Python loop. Do NOT regress to a `for row in range(POLAR_RADIAL): for col in range(POLAR_ANGULAR):` Python loop — that would defeat the "Don't Hand-Roll" guidance.
